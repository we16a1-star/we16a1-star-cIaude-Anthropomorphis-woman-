Claude 娘 Windows 11 電腦版 4.6.36 G42 更新說明

更新內容

1. 故事 AI 輸出契約新增 emotion 與 intensity 欄位，API 與網頁模式使用相同的情緒值與正規化規則。
2. 新增 focused（專注），與 curious（好奇）分開；專注適用於閱讀、思考、解題與認真聆聽。
3. intensity 限制為 1～3，供表情光暈、立繪動作幅度及情緒停留時間使用。舊回覆缺少 intensity 時相容為 1，未知情緒安全回到 neutral。
4. 情緒強度與情緒值會隨故事存檔及回合重寫快照保存。
5. 得意、害羞、好奇與專注都加入停留期限並自然回到日常；同一情緒 6 秒內再次觸發會延長停留，不重播進場動作。
6. 故事立繪新增日常、得意、害羞、專注四張臉部差分，AI 的 neutral／proud／shy／focused 各自顯示對應裁切圖並短暫停留。
7. 四張 256×256 WebP 在本機裁切、放大與轉檔，沒有呼叫外部影像 API。日常、得意、害羞取自「Claude娘圖3.jpg」表情格；專注改由「portrait-start.webp」裁切，保留低頭閱讀神情並去除眼鏡。底圖保持靜止，不做整圖網格扭曲，只搭配小幅 CSS 姿勢。
8. 好感度設定仍只控制畫面上好感度欄的顯示／隱藏，不改數值、計算或遊戲機制。

驗收

- 372 項完整自動化回歸測試全數通過（0 失敗），涵蓋 API、網頁模式、七選項、存檔回退與 UI 接線。
- 前端 bundle、立繪模組、情緒正規化模組、模型檢查器與 API 伺服器皆通過 Node 語法檢查。
- Windows x64 安裝程式建置完成；本版尚未安裝或啟動。
